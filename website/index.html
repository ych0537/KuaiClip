// features

需要的内容，就在指尖。

--search

瞬间找到

输入即筛选。文本、链接、文件路径和图片，都能快速回到手边。

--keyboard

键盘优先

方向键选择，Enter 复制，Option + Enter 直接粘贴。工作流无需离开键盘。

--ai-polish

聪明的 AI 润色

只对自然语言显示润色按钮；命令、URL、代码与结构化数据不会被打扰。

--pin

常用内容置顶

固定最多 10 条常用片段，以 A–J 快捷键随时取用。

--json

JSON 一键整形

自动识别有效 JSON，一键格式化、复制并保存到剪贴板历史。

--ocr

本机图片识别

使用 Apple Vision 在本机提取图片中的文字，原图不上传。

--theme

六套配色

白色、浅蓝、薄荷绿、暖米色、淡紫与黑色主题，一键循环切换。

--screenshot

截图与标注

截取区域、窗口或全屏，添加图形、箭头、画笔、马赛克、文字和编号，再保存或复制。

// keymap

手不用离开键盘。

⌘ ⌘呼出剪贴板历史（双击左 Command）
↑ ↓选择条目
↵复制到剪贴板
⌥ ↵直接粘贴到当前应用
A–J取用固定的片段

// privacy

你的剪贴板，
留在你的 Mac。

历史数据存储在本机，不上传遥测或剪贴板内容。AI 润色仅在你主动点击时连接服务商，API 密钥由 macOS 钥匙串保护。

KuaiPop

选中文字，一键翻译・润色・ToDo

在任意应用中选中文字，旁边立刻弹出图标条。结果直接显示在原文下方，不打断你的工作。

  • --translate日语・英语 → 中文，中文 → 日语；一键切换 中 / 日 / EN
  • --polish润色为商务日语，输入框中可直接替换原文
  • --todo静默加入 ToDo，AI 自动提取标题与期限
  • --aiMac 本机 AI（Apple Intelligence）/ Azure OpenAI / DeepSeek / Ollama
